The program reads a CSV dataset (prompting the user for a file path) and stores each line as a row in a list. It then shows a menu letting the user pick one of three “machine problems”: (MP02) display the first 10 non-empty/data rows, (MP03) search the dataset for a keyword and print matching rows, or (MP04) count how many non-empty rows exist. It treats “empty” rows as those that are blank or contain only commas/quotes/whitespace. The menu repeats until the user chooses “X” to exit, and any file-read errors are reported and stop execution.
